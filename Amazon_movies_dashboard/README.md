# Prime Video Data Dashboard

This repository contains a Power BI dashboard that visualizes various insights from a dataset of Prime Video content. The dashboard provides an overview of the platform's shows and movies, categorized by ratings, genres, release years, and more.

## Features

### 1. **Total Titles**
   - Displays the total number of titles (movies and TV shows) available on Prime Video: **9,655**.

### 2. **Total Ratings**
   - Indicates the number of unique content ratings in the dataset: **25**.

### 3. **Total Genres**
   - Highlights the total number of distinct genres present: **519**.

### 4. **Number of Directors**
   - Shows the total number of directors associated with the content: **5,771**.

### 5. **Time Span**
   - Covers a span of **101 years**, ending in **2021**.

### 6. **Ratings by Total Shows**
   - Bar chart showing the distribution of shows by their content ratings:
     - 13+: **2.1K**
     - 16+: **1.5K**
     - ALL: **1.3K**
     - 18+: **1.2K**
     - R: **1.0K**
     - PG-13: **0.4K**

### 7. **Genres by Total Shows**
   - Bar chart displaying the top genres based on the number of shows:
     - Drama: **986**
     - Comedy: **536**
     - Drama, Suspense: **399**
     - Comedy, Drama: **377**
     - Animation, Kids: **356**
     - Documentary: **350**

### 8. **Total Shows by Country**
   - World map visualizing the geographical distribution of shows, highlighting regions with the most content.

### 9. **Movies and TV Shows**
   - Pie chart showing the proportion of movies to TV shows:
     - TV Shows: **80.82%** (7.81K)
     - Movies: **19.18%** (1.85K)

### 10. **Total Shows by Release Year**
   - Area chart showing the distribution of shows over different release years, with a noticeable decline in recent years.

## How to Use
- Clone the repository and open the Power BI file to explore the dashboard.
- The dashboard provides interactive elements, allowing users to filter and analyze the data based on specific criteria like genres, ratings, and release years.
